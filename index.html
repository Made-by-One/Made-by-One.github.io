Devers Launcher

Modern game launcher for .dvp archives

Devers Launcher

v1.4 · Windows · MIT

A clean, modern launcher for .dvp games created with Devers Packer. Extracts each game into a temp folder, runs it, and cleans everything up when you close it — no leftover files on your disk.

Devers Packer

Pack any game folder into a single .dvp archive

Devers Packer

v1.1 · Windows · MIT

Turns any game folder into a single .dvp archive — ZIP-based, maximum compression, with an embedded manifest and a cover. The cover editor lets you crop and scale any image to 240×175 with a live preview.

.dvp format Max compression Cover editor Auto .exe detect Manifest Multi-language
