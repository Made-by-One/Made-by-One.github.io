Решение проблем

СимптомПричина и решение
Каталог пустЗапрос реестра не прошёл или фильтр стоит на игре без модов. Обновите каталог и переключитесь на Все игры.
No mods folder at …Моды ещё не установлены или игра сканирует другую папку, чем профиль. Задайте папку в профиле или передайте modsRoot.
Мод найден, но пропущенgame_id не совпадает с Initialize(gameId: …).
no AssetBundle foundВ папке нет .bundle, .unity3d или .bytes, и в манифесте не указаны bundles.
Ассет грузится, но префаб розовыйШейдеры или текстуры лежат в другом бандле. Кладите зависимости в мод и загружайте все бандлы.
Android: The archive is corruptedПересоберите бандл со сжатием LZ4.
GitHub API 401Токен отсутствует или истёк — выйдите и войдите снова.
GitHub API 403 / 404У токена нет доступа к нужному репозиторию или сработал лимит. Войдите заново или выберите другой репозиторий.
GitHub API 422Релизный тег отклонён или файл слишком большой. Поднимите версию и держите файлы заметно меньше 100 МБ.
Конфликт pull requestДругой открытый pull request меняет тот же файл мода. Закройте старый и опубликуйте снова.
Мод не появился после mergeНе прошла пересборка. Откройте Actions → Rebuild Mod Registry в репозитории и прочитайте лог.
У игроков Checksum mismatchAsset релиза изменился после публикации. Опубликуйте снова, чтобы SHA-256 совпал.
