Pour les développeurs de jeux

Unity SDK

unity-sdk/WorkmodsSDK.cs est un unique fichier C# sans dépendances qui analyse un dossier de mods, expose les mods installés et charge leurs assets.

  1. Copie WorkmodsSDK.cs dans ton projet, par exemple Assets/Workmods/.
  2. Décide où vivent les mods. Le client utilise ~/DeversMods/<game_id> par défaut ; le SDK utilise Application.persistentDataPath/Workmods. Pointe le profil du jeu vers le dossier que ton jeu analyse, ou passe modsRoot à l'initialisation.
  3. Initialise une fois, puis charge par id de mod et nom d'asset.
using Workmods;
using UnityEngine;

public class Mods : MonoBehaviour
{
    private void Awake()
    {
        WorkmodsSDK.Initialize(
            modsRoot: null,            // null → persistentDataPath/Workmods
            gameId: "space-rangers",   // refuser les mods des autres jeux
            verboseLogging: true,
            writeLogToFile: true);     // <modsRoot>/workmods.log
    }
}

// charger un prefab d'un mod installé
var prefab = WorkmodsSDK.LoadAsset<GameObject>("a1b2c3d4", "NeonHud");
if (prefab != null) Instantiate(prefab);
MembreDescription
Initialize(...)Analyse le dossier. Appel répétable.
Rescan()Relit le dossier après une installation en jeu.
GetInstalledMods()Mods installés, filtrés par gameId.
GetInstalledMod(id), IsInstalled(id)Aides de recherche, insensibles à la casse.
LoadAssetBundle(id, name)UnityEngine.Object ou null ; la raison est journalisée.
LoadAsset<T>(id, name)Variante typée, par exemple <GameObject>.
LoadBundles(mod)Charge et met en cache tous les bundles d'un mod, dépendances comprises.
TryLoadAssembly(id, out asm)Mono uniquement ; renvoie false sous IL2CPP.
UnloadAssetBundle(id), UnloadAll()Décharge les bundles ; détruis d'abord les instances.
WorkmodsLog.OnLogRedirige les messages du SDK vers ton propre logger.
  • Tout s'exécute sur le thread principal ; ne charge pas de bundles depuis des threads de travail.
  • Les mods désactivés sont dans .workmods-disabled/ et sont ignorés automatiquement à l'analyse suivante.
  • Windows, macOS et Linux standalone sont pleinement pris en charge ; Android exige des bundles LZ4 ; iOS fonctionne avec des AssetBundles installés par ton interface ; les consoles demandent un packaging spécifique.
  • WebGL n'est pas pris en charge : pas d'accès fichier synchrone, il faudrait un chargeur asynchrone.
