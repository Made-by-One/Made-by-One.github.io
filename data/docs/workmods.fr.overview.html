Devers Workmods

Workmods est un gestionnaire de mods universel pour les jeux Unity. Trois parties partagent un même contrat — l'entrée du registre : un mod publié une fois apparaît dans le catalogue de chaque joueur, s'installe dans le bon dossier et se charge via le SDK du jeu, sans travail supplémentaire par jeu.

PartieCe qu'elle fait
Client de bureau Application Python + PyQt6 pour les joueurs et les auteurs : parcourir le catalogue, installer, mettre à jour, activer ou désactiver des mods et publier dans son propre dépôt GitHub.
Registre registry.json dans le dépôt Workmods, régénéré par GitHub Actions à partir d'un fichier de soumission par mod. Les clients le lisent depuis raw.githubusercontent.com.
Unity SDK Un seul fichier C# sans dépendances qui analyse le dossier des mods, liste les mods installés et charge leurs AssetBundles.
  • Version actuelle : 1.3b, bêta publique avec des builds Windows x64, Linux x86_64 et macOS.
  • Licence MIT, sans télémétrie ni service en arrière-plan.
  • Les mods vivent dans le dépôt GitHub du moddeur et sont distribués via GitHub Releases. Le client n'écrit jamais dans le registre partagé : il ouvre une pull request.
