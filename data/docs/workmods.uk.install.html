Встановлення та перший запуск

  1. Відкрийте сторінку Releases і завантажте архів для своєї системи: Workmods-windows-x86_64.zip, Workmods-linux-x86_64.tar.gz або Workmods-macos.zip.
  2. Розпакуйте будь-де. Збірка переносна: стан зберігається в домашній теці, а не поруч із виконуваним файлом.
  3. Запустіть Workmods.exe у Windows, ./Workmods у Linux (після chmod +x Workmods) або Workmods.app у macOS.
  4. Під час першого запуску клієнт завантажує реєстр, визначає мову системи й створює профіль гри за замовчуванням.

Інтерфейс перекладено шістьма мовами — англійською, російською, німецькою, іспанською, французькою та китайською — і перемикається в налаштуваннях миттєво. До входу через GitHub каталог працює лише для читання; для встановлення й оновлення модів акаунт не потрібен.

Оновлення Налаштування → Оновлення застосунку перевіряють GitHub Releases, звіряють SHA256SUMS і відокремлений підпис, якщо він опублікований, зберігають копію попереднього виконуваного файлу й уміють відкотитися, якщо оновлення не застосувалося.
