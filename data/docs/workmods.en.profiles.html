Game profiles

One installation of Workmods manages mods for any number of Unity games. A profile is a record of { id, name, install_dir, sdk }; the registry only stores the game_id, so nothing is tied to one machine.

  1. Open Settings → Game Profiles and choose Add Game.
  2. Enter a Game ID in lower case (a-z, 0-9, ., _, -) — the exact value the game passes to WorkmodsSDK.Initialize.
  3. Set a display name and the install directory the game scans. Empty means ~/DeversMods/<game_id>.
  4. Pick the profile as the active game. Catalog and Installed both filter to it; All games shows everything.
Folder The default profile is called “Unassigned”, cannot be removed and keeps mods that do not declare a game_id. The Unity SDK defaults to Application.persistentDataPath/Workmods, so either point the profile at that folder or pass the profile's directory to Initialize.
