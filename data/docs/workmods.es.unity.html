Para desarrolladores de juegos

Unity SDK

unity-sdk/WorkmodsSDK.cs es un único archivo C# sin dependencias que escanea una carpeta de mods, expone los instalados y carga sus assets.

  1. Copia WorkmodsSDK.cs en tu proyecto, por ejemplo en Assets/Workmods/.
  2. Decide dónde viven los mods. El cliente usa por defecto ~/DeversMods/<game_id>; el SDK usa Application.persistentDataPath/Workmods. Apunta el perfil del juego a la carpeta que escanea tu juego o pasa modsRoot al inicializar.
  3. Inicializa una vez y luego carga por id de mod y nombre de asset.
using Workmods;
using UnityEngine;

public class Mods : MonoBehaviour
{
    private void Awake()
    {
        WorkmodsSDK.Initialize(
            modsRoot: null,            // null → persistentDataPath/Workmods
            gameId: "space-rangers",   // rechazar mods de otros juegos
            verboseLogging: true,
            writeLogToFile: true);     // <modsRoot>/workmods.log
    }
}

// cargar un prefab de un mod instalado
var prefab = WorkmodsSDK.LoadAsset<GameObject>("a1b2c3d4", "NeonHud");
if (prefab != null) Instantiate(prefab);
MiembroDescripción
Initialize(...)Escanea la carpeta. Se puede llamar varias veces.
Rescan()Vuelve a leer la carpeta tras una instalación en el juego.
GetInstalledMods()Mods instalados, filtrados por gameId.
GetInstalledMod(id), IsInstalled(id)Búsqueda auxiliar, sin distinguir mayúsculas.
LoadAssetBundle(id, name)UnityEngine.Object o null; registra el motivo del fallo.
LoadAsset<T>(id, name)Variante tipada, por ejemplo <GameObject>.
LoadBundles(mod)Carga y cachea todos los bundles de un mod, resolviendo dependencias.
TryLoadAssembly(id, out asm)Solo Mono; devuelve false en IL2CPP.
UnloadAssetBundle(id), UnloadAll()Descarga bundles; destruye antes las instancias.
WorkmodsLog.OnLogEnvía los mensajes del SDK a tu propio logger.
  • Todo se ejecuta en el hilo principal; no cargues bundles desde hilos de trabajo.
  • Los mods desactivados están en .workmods-disabled/ y se omiten automáticamente en el siguiente escaneo.
  • Windows, macOS y Linux standalone están totalmente soportados; Android necesita bundles LZ4; iOS funciona con AssetBundles instalados desde tu propia interfaz; las consolas requieren empaquetado específico.
  • WebGL no está soportado: no tiene acceso sincrónico a archivos y necesita un cargador asíncrono.
