安装

安装与首次启动

  1. 打开 Releases 页面，下载对应系统的压缩包：Workmods-windows-x86_64.zip、Workmods-linux-x86_64.tar.gz 或 Workmods-macos.zip。
  2. 解压到任意位置。构建是便携的：状态保存在个人目录，而不是可执行文件旁边。
  3. 启动 Workmods.exe（Windows）、./Workmods（Linux，先执行 chmod +x Workmods）或 Workmods.app（macOS）。
  4. 首次启动时，客户端会拉取注册表、检测系统语言并创建默认游戏配置。

界面提供六种语言——英语、俄语、德语、西班牙语、法语和中文——可在设置中即时切换。未登录 GitHub 时目录为只读；安装和更新模组无需账号。

更新 设置 → 应用更新会检查 GitHub Releases，校验 SHA256SUMS 以及已发布的分离签名，保留上一版可执行文件的备份，并在更新失败时回滚。
