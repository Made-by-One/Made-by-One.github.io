Spielprofile

Eine Workmods-Installation verwaltet Mods für beliebig viele Unity-Spiele. Ein Profil ist ein Datensatz { id, name, install_dir, sdk }; die Registry speichert nur die game_id, damit nichts an einen Rechner gebunden ist.

  1. Öffne Einstellungen → Spielprofile und wähle Spiel hinzufügen.
  2. Trage eine Game ID in Kleinbuchstaben ein (a-z, 0-9, ., _, -) — genau den Wert, den das Spiel an WorkmodsSDK.Initialize übergibt.
  3. Setze Anzeigenamen und den Installationsordner, den das Spiel scannt. Leer bedeutet ~/DeversMods/<game_id>.
  4. Wähle das Profil als aktives Spiel. Katalog und Installiert filtern danach; Alle Spiele zeigt alles.
Ordner Das Standardprofil heißt „Unassigned“, lässt sich nicht entfernen und behält Mods ohne game_id. Das Unity SDK nutzt standardmäßig Application.persistentDataPath/Workmods — richte das Profil auf diesen Ordner oder übergib den Profilordner an Initialize.
