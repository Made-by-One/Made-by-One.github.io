Unity SDK

unity-sdk/WorkmodsSDK.cs — один C#-файл без залежностей: сканує теку модів, віддає встановлені та завантажує їхні асети.

  1. Скопіюйте WorkmodsSDK.cs у проєкт, наприклад у Assets/Workmods/.
  2. Вирішіть, де лежать моди. Клієнт за замовчуванням ставить їх у ~/DeversMods/<game_id>, а SDK за замовчуванням дивиться в Application.persistentDataPath/Workmods. Спрямуйте профіль гри на теку, яку сканує гра, або передайте modsRoot під час ініціалізації.
  3. Ініціалізуйте один раз, потім завантажуйте за id мода та іменем асета.
using Workmods;
using UnityEngine;

public class Mods : MonoBehaviour
{
    private void Awake()
    {
        WorkmodsSDK.Initialize(
            modsRoot: null,            // null → persistentDataPath/Workmods
            gameId: "space-rangers",   // відхилити моди для інших ігор
            verboseLogging: true,
            writeLogToFile: true);     // <modsRoot>/workmods.log
    }
}

// завантажити префаб із встановленого мода
var prefab = WorkmodsSDK.LoadAsset<GameObject>("a1b2c3d4", "NeonHud");
if (prefab != null) Instantiate(prefab);
ЧленОпис
Initialize(...)Сканує теку. Можна викликати повторно.
Rescan()Перечитати теку після встановлення з гри.
GetInstalledMods()Встановлені моди з фільтром за gameId.
GetInstalledMod(id), IsInstalled(id)Пошук без урахування регістру.
LoadAssetBundle(id, name)UnityEngine.Object або null; причина помилки пишеться в лог.
LoadAsset<T>(id, name)Типізований варіант, наприклад <GameObject>.
LoadBundles(mod)Завантажити й закешувати всі бандли мода з урахуванням залежностей.
TryLoadAssembly(id, out asm)Лише Mono; на IL2CPP повертає false.
UnloadAssetBundle(id), UnloadAll()Вивантажити бандли — спершу знищте екземпляри.
WorkmodsLog.OnLogСпрямувати повідомлення SDK у власний логер.
  • Усе виконується в головному потоці; не завантажуйте бандли з робочих потоків.
  • Вимкнені моди лежать у .workmods-disabled/ і пропускаються під час наступного сканування.
  • Windows, macOS і Linux standalone підтримуються повністю; на Android потрібні LZ4-бандли; на iOS працюють AssetBundle, встановлені через ваш інтерфейс; консолі потребують платформного пакування.
  • WebGL не підтримується: там немає синхронного доступу до файлів і потрібен асинхронний завантажувач.
