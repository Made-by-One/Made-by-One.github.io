Perfiles de juego

Una instalación de Workmods gestiona mods para cualquier número de juegos de Unity. Un perfil es un registro { id, name, install_dir, sdk }; el registro compartido solo guarda el game_id, así que nada queda atado a una máquina.

  1. Abre Ajustes → Perfiles de juego y elige Añadir juego.
  2. Escribe un Game ID en minúsculas (a-z, 0-9, ., _, -): el valor exacto que el juego pasa a WorkmodsSDK.Initialize.
  3. Indica un nombre visible y la carpeta de instalación que escanea el juego. Si se deja vacía, es ~/DeversMods/<game_id>.
  4. Elige el perfil como juego activo. Catálogo e Instalados se filtran por él; Todos los juegos muestra todo.
Carpeta El perfil por defecto se llama «Unassigned», no se puede eliminar y conserva los mods sin game_id. El SDK de Unity usa por defecto Application.persistentDataPath/Workmods, así que apunta el perfil a esa carpeta o pasa la carpeta del perfil a Initialize.
