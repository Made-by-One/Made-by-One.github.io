Unity SDK

unity-sdk/WorkmodsSDK.cs — один C#-файл без зависимостей: сканирует папку модов, отдаёт установленные и загружает их ассеты.

  1. Скопируйте WorkmodsSDK.cs в проект, например в Assets/Workmods/.
  2. Решите, где лежат моды. Клиент по умолчанию ставит их в ~/DeversMods/<game_id>, а SDK по умолчанию смотрит в Application.persistentDataPath/Workmods. Направьте профиль игры на папку, которую сканирует игра, либо передайте modsRoot при инициализации.
  3. Инициализируйте один раз, затем загружайте по id мода и имени ассета.
using Workmods;
using UnityEngine;

public class Mods : MonoBehaviour
{
    private void Awake()
    {
        WorkmodsSDK.Initialize(
            modsRoot: null,            // null → persistentDataPath/Workmods
            gameId: "space-rangers",   // отклонить моды для других игр
            verboseLogging: true,
            writeLogToFile: true);     // <modsRoot>/workmods.log
    }
}

// загрузить префаб из установленного мода
var prefab = WorkmodsSDK.LoadAsset<GameObject>("a1b2c3d4", "NeonHud");
if (prefab != null) Instantiate(prefab);
ЧленОписание
Initialize(...)Сканирует папку. Можно вызывать повторно.
Rescan()Перечитать папку после установки из игры.
GetInstalledMods()Установленные моды с фильтром по gameId.
GetInstalledMod(id), IsInstalled(id)Поиск без учёта регистра.
LoadAssetBundle(id, name)UnityEngine.Object или null; причина ошибки пишется в лог.
LoadAsset<T>(id, name)Типизированный вариант, например <GameObject>.
LoadBundles(mod)Загрузить и закешировать все бандлы мода с учётом зависимостей.
TryLoadAssembly(id, out asm)Только Mono; на IL2CPP возвращает false.
UnloadAssetBundle(id), UnloadAll()Выгрузить бандлы — сначала уничтожьте экземпляры.
WorkmodsLog.OnLogПеренаправить сообщения SDK в свой логгер.
  • Всё выполняется в главном потоке; не загружайте бандлы из рабочих потоков.
  • Отключённые моды лежат в .workmods-disabled/ и пропускаются при следующем сканировании.
  • Windows, macOS и Linux standalone поддерживаются полностью; на Android нужны LZ4-бандлы; на iOS работают AssetBundle, установленные через ваш интерфейс; консоли требуют платформенной упаковки.
  • WebGL не поддерживается: там нет синхронного доступа к файлам и нужен асинхронный загрузчик.
