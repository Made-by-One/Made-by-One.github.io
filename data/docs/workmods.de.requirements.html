Anforderungen & Abhängigkeiten

Die Release-Builds sind eigenständig: Python und PyQt6 sind enthalten, Spieler installieren nichts weiter. Aus dem Quellcode starten ist nur für die Entwicklung nötig.

Fertiger Client

  • Windows 10/11 x64, Linux x86_64 (auf Ubuntu 22.04 gebaut, läuft mit neuerem glibc) oder macOS.
  • Kein Python, kein Qt, keine Admin-Rechte. Unter Linux einmal chmod +x.
  • Netzwerk für den Katalog. Ein GitHub-Konto braucht nur, wer Mods erstellt oder veröffentlicht.

Unter Linux werden die Qt-Laufzeitbibliotheken benötigt:

sudo apt-get install -y libxkbcommon0 libxkbcommon-x11-0 libfontconfig1 \
  libfreetype6 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libgl1 libegl1
Ohne Oberfläche Die Autoren-CLI (python -m workmods) importiert kein Qt und läuft daher ohne Display auf einem Build-Rechner oder in CI.

Unity SDK

  • C# 7.3 und Unity 2019.4 oder neuer; läuft mit Mono und IL2CPP, das Nachladen von DLLs geht aber nur mit Mono.
  • Weder Paketmanager noch Assembly Definition nötig — eine Datei in Assets/ genügt.
  • AssetBundles funktionieren auf allen Unity-Plattformen; WebGL unterstützt das SDK nicht.

Wo alles liegt

Das Konfigurationsverzeichnis lässt sich über WORKMODS_CONFIG_DIR verschieben, die Registry-Quelle über WORKMODS_REGISTRY_REPO und WORKMODS_REGISTRY_BRANCH.
