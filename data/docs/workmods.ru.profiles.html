Профили игр

Одна установка Workmods обслуживает любое число игр на Unity. Профиль — это запись { id, name, install_dir, sdk }; реестр хранит только game_id, поэтому ничего не привязано к одной машине.

  1. Откройте Настройки → Профили игр и нажмите Добавить игру.
  2. Укажите Game ID в нижнем регистре (a-z, 0-9, ., _, -) — ровно то значение, которое игра передаёт в WorkmodsSDK.Initialize.
  3. Задайте отображаемое имя и папку установки, которую сканирует игра. Пустое поле означает ~/DeversMods/<game_id>.
  4. Выберите профиль как активную игру. Каталог и «Установленные» фильтруются по нему; Все игры показывает всё.
Папка Профиль по умолчанию называется «Unassigned», его нельзя удалить, и в нём остаются моды без game_id. Unity SDK по умолчанию смотрит в Application.persistentDataPath/Workmods, поэтому либо направьте профиль на эту папку, либо передайте папку профиля в Initialize.
