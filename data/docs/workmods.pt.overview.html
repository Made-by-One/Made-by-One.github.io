Devers Workmods

Workmods é um gerenciador universal de mods para jogos Unity. Ele tem três partes que compartilham um contrato — a entrada no registro: um mod publicado uma vez aparece no catálogo de cada jogador, instala-se na pasta certa e carrega pelo SDK do jogo sem trabalho extra por jogo.

ParteO que faz
Cliente desktop Aplicativo em Python + PyQt6 para jogadores e autores: navegar no catálogo, instalar, atualizar, ativar ou desativar mods e publicar no próprio repositório GitHub.
Registro registry.json no repositório do Workmods, reconstruído pelo GitHub Actions a partir de um arquivo de envio por mod. Os clientes o leem de raw.githubusercontent.com.
Unity SDK Um único arquivo C# sem dependências que varre a pasta de mods, lista os instalados e carrega seus AssetBundles.
  • Versão atual: 1.2b, beta pública com builds para Windows x64, Linux x86_64 e macOS.
  • Licença MIT, sem telemetria e sem serviços em segundo plano.
  • Os mods ficam no repositório GitHub do próprio modder e são distribuídos via GitHub Releases. O cliente nunca escreve no registro compartilhado: ele abre um pull request.
