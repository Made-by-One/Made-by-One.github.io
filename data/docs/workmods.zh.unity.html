Unity SDK

unity-sdk/WorkmodsSDK.cs 是一个无依赖的 C# 文件：扫描模组文件夹、列出已安装模组并加载其资源。

  1. 把 WorkmodsSDK.cs 复制到项目中，例如 Assets/Workmods/。
  2. 决定模组存放位置。客户端默认使用 ~/DeversMods/<game_id>，而 SDK 默认使用 Application.persistentDataPath/Workmods。把游戏配置指向游戏扫描的目录，或在初始化时传入 modsRoot。
  3. 初始化一次，然后按模组 id 与资源名加载。
using Workmods;
using UnityEngine;

public class Mods : MonoBehaviour
{
    private void Awake()
    {
        WorkmodsSDK.Initialize(
            modsRoot: null,            // null → persistentDataPath/Workmods
            gameId: "space-rangers",   // 拒绝为其他游戏发布的模组
            verboseLogging: true,
            writeLogToFile: true);     // <modsRoot>/workmods.log
    }
}

// 从已安装模组加载预制体
var prefab = WorkmodsSDK.LoadAsset<GameObject>("a1b2c3d4", "NeonHud");
if (prefab != null) Instantiate(prefab);
成员说明
Initialize(...)扫描目录，可重复调用。
Rescan()在游戏内安装后重新读取目录。
GetInstalledMods()已安装模组，按 gameId 过滤。
GetInstalledMod(id)、IsInstalled(id)查找辅助方法，不区分大小写。
LoadAssetBundle(id, name)返回 UnityEngine.Object 或 null，失败原因写入日志。
LoadAsset<T>(id, name)带类型版本，例如 <GameObject>。
LoadBundles(mod)加载并缓存模组的所有 bundle，处理依赖关系。
TryLoadAssembly(id, out asm)仅 Mono；IL2CPP 下返回 false。
UnloadAssetBundle(id)、UnloadAll()卸载 bundle，请先销毁实例。
WorkmodsLog.OnLog把 SDK 消息接入自己的日志系统。
  • 全部在主线程执行；不要在工作线程中加载 bundle。
  • 已停用的模组位于 .workmods-disabled/，下次扫描会自动跳过。
  • Windows、macOS 与 Linux 独立版完整支持；Android 需要 LZ4 bundle；iOS 可通过自己的界面安装 AssetBundle；主机平台需要相应打包流程。
  • 不支持 WebGL：它没有同步文件访问，需要异步加载器。
