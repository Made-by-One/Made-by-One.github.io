Devers Workmods

Workmods es un gestor universal de mods para juegos de Unity. Tiene tres partes que comparten un contrato —la entrada del registro—: un mod publicado una vez aparece en el catálogo de cada jugador, se instala en la carpeta correcta y se carga mediante el SDK del juego sin trabajo adicional por juego.

ParteQué hace
Cliente de escritorio Aplicación en Python + PyQt6 para jugadores y autores: explorar el catálogo, instalar, actualizar, activar o desactivar mods y publicar en tu propio repositorio de GitHub.
Registro registry.json en el repositorio de Workmods, que GitHub Actions regenera a partir de un archivo de envío por mod. Los clientes lo leen desde raw.githubusercontent.com.
Unity SDK Un único archivo C# sin dependencias que escanea la carpeta de mods, lista los instalados y carga sus AssetBundles.
  • Versión actual: 1.3b, beta pública con compilaciones para Windows x64, Linux x86_64 y macOS.
  • Licencia MIT, sin telemetría ni servicios en segundo plano.
  • Los mods viven en el repositorio de GitHub del propio modder y se distribuyen mediante GitHub Releases. El cliente nunca escribe en el registro compartido: abre un pull request.
