故障排查

现象原因与解决
目录为空注册表请求失败，或筛选的是没有模组的游戏。刷新后切换到所有游戏。
No mods folder at …尚未安装任何模组，或游戏扫描的目录与配置不同。设置配置目录或传入 modsRoot。
找到模组但被跳过game_id 与 Initialize(gameId: …) 不一致。
no AssetBundle found文件夹中没有 .bundle、.unity3d 或 .bytes，且清单未列出 bundles。
资源加载了，但预制体是粉色着色器或贴图位于另一个 bundle。把依赖放进模组并加载所有 bundle。
Android：The archive is corrupted用 LZ4 压缩重新构建 bundle。
GitHub API 401令牌缺失或过期——退出后重新登录。
GitHub API 403 / 404令牌无权访问目标仓库，或触发了频率限制。重新登录或选择其他仓库。
GitHub API 422发行标签被拒绝或文件过大。提升版本，并让文件明显小于 100 MB。
pull request 冲突另一个未合并的 pull request 修改了同一个模组文件。关闭旧的再重新发布。
合并后模组仍未出现重建失败。打开仓库的 Actions → Rebuild Mod Registry 查看日志。
玩家遇到 Checksum mismatch发布后发行资源被改动。重新发布以让 SHA-256 一致。
