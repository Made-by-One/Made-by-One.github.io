Installation

Installation & erster Start

  1. Öffne die Releases-Seite und lade das Archiv für dein System: Workmods-windows-x86_64.zip, Workmods-linux-x86_64.tar.gz oder Workmods-macos.zip.
  2. Irgendwo entpacken. Der Build ist portabel: Der Zustand liegt im Home-Verzeichnis, nicht neben der ausführbaren Datei.
  3. Starte Workmods.exe unter Windows, ./Workmods unter Linux (nach chmod +x Workmods) oder Workmods.app unter macOS.
  4. Beim ersten Start lädt der Client die Registry, erkennt die Systemsprache und legt das Standard-Spielprofil an.

Die Oberfläche gibt es in sechs Sprachen — Englisch, Russisch, Deutsch, Spanisch, Französisch und Chinesisch — und wechselt in den Einstellungen sofort. Bis zur GitHub-Anmeldung ist der Katalog schreibgeschützt; Installieren und Aktualisieren braucht kein Konto.

Updates Einstellungen → App-Updates prüfen GitHub Releases, verifizieren SHA256SUMS und die abgetrennte Signatur, wenn eine veröffentlicht ist, sichern die vorherige ausführbare Datei und können zurückrollen, wenn das Update fehlschlägt.
