Criar um mod

Um mod é uma pasta. Seu conteúdo é exatamente o que o SDK do jogo verá, mais um manifesto opcional workmod.json.

neon-ui/
├── workmod.json
├── neon-ui.bundle
└── bundles/
    └── shared.bundle

O manifesto

Ao publicar, o cliente exige apenas name e version, mas id, game_id e os campos de compatibilidade permitem que o validador rejeite um pacote que não roda no alvo.

CampoSignificado
idId estável do mod. Gerado uma vez, nunca alterado entre versões.
game_idJogo alvo. Por padrão, o perfil default.
name, versionNome e versão. A tag do release vira v<version>.
author, descriptionTexto livre exibido no catálogo.
entry_assetNome de asset padrão opcional que o jogo pode carregar.
bundlesCaminhos explícitos de bundles relativos à raiz do mod. Recomendado quando os nomes são ambíguos.
engine, sdkunity para o SDK atual.
unity_versionVersão mínima do Unity para a qual o mod foi compilado.
platformswindows, linux, macos, android, ios.
min_client_version, min_sdk_versionCliente e SDK mais antigos capazes de instalar ou carregar o mod.
tagsStrings para busca.
 
{
  "id": "a1b2c3d4",
  "game_id": "space-rangers",
  "name": "Neon UI",
  "version": "1.2.0",
  "author": "your-handle",
  "description": "Neon HUD replacement for the tactical screen.",
  "entry_asset": "NeonHud",
  "bundles": ["neon-ui.bundle", "bundles/shared.bundle"],
  "engine": "unity",
  "unity_version": "2021.3",
  "platforms": ["windows", "linux", "macos"],
  "tags": ["ui", "hud"]
}

Formato do conteúdo

  • AssetBundles são o formato recomendado: funcionam com Mono e IL2CPP em todas as plataformas. Compile um bundle por plataforma — ele não é portátil entre elas.
  • Use ChunkBasedCompression (LZ4). Bundles LZMA precisam ser descompactados por inteiro e são uma causa comum de falhas no Android.
  • Inclua as dependências (bundles compartilhados, texturas, shaders) dentro do mod. O SDK carrega todos os bundles do mod antes de resolver os assets.
  • Addressables funcionam porque geram AssetBundles; inclua os arquivos de bundle compilados da pasta da plataforma.
  • DLLs só carregam no backend de scripts Mono. Trate-as como código totalmente confiável.
using UnityEditor;
using UnityEngine;

public static class WorkmodsBundleBuilder
{
    [MenuItem("Workmods/Build Mod Bundle")]
    public static void Build()
    {
        var builds = new[]
        {
            new AssetBundleBuild
            {
                assetBundleName = "neon-ui.bundle",
                assetNames = new[] { "Assets/ModContent/NeonHud.prefab" }
            }
        };

        BuildPipeline.BuildAssetBundles(
            "Build/Mod", builds,
            BuildAssetBundleOptions.ChunkBasedCompression,
            BuildTarget.StandaloneWindows64);
    }
}

CLI de autor

O editor desktop basta, mas os mesmos utilitários existem no terminal e em CI. Cada comando sai com código diferente de zero em caso de erro e aceita --json para saída legível por máquina.

# criar uma pasta com workmod.json preenchido
python -m workmods init neon-ui --name "Neon UI" --game space-rangers --author your-handle

# verificar campos obrigatórios, bundles e conteúdo ausente
python -m workmods validate neon-ui

# montar o ZIP de release e imprimir seu SHA-256
python -m workmods pack neon-ui --out dist/neon-ui.zip

# reabrir o ZIP e conferir conteúdo e digest
python -m workmods validate-package dist/neon-ui.zip --sha256 <digest>

# verificar compatibilidade com um alvo concreto
python -m workmods validate-package dist/neon-ui.zip \
  --engine unity --unity-version 2022.3 --platform windows --platform linux

No editor

  1. Author Studio → Login via GitHub e depois Novo repositório para criar um repositório público com commit inicial (ou escolha um existente).
  2. Criar a ficha do mod: o id é gerado; preencha jogo alvo, nome, versão, autor, descrição, ícone e banner, tags e a pasta de arquivos. Um workmod.json nessa pasta preenche os campos vazios.
  3. Salvar mod grava um rascunho local na pasta de instalação do jogo, para instalar e testar em jogo antes de publicar.
Limpeza O empacotamento ignora .devers_meta.json, .git, __pycache__, .DS_Store, Thumbs.db e .workmods-disabled, mas vale manter a pasta organizada.
