Devers Workmods

Workmods 是一款面向 Unity 游戏的通用模组管理器。它由三部分组成，共享同一个约定——注册表条目： 模组只需发布一次，就会出现在每位玩家的目录中，安装到正确的文件夹，并通过游戏内的 SDK 加载， 无需为每个游戏单独适配。

组成作用
桌面客户端 基于 Python + PyQt6，面向玩家与作者：浏览目录、安装、更新、启用或停用模组，并发布到自己的 GitHub 仓库。
注册表 Workmods 仓库中的 registry.json，由 GitHub Actions 根据每个模组的一份提交文件重建。客户端从 raw.githubusercontent.com 读取。
Unity SDK 单个无依赖的 C# 文件：扫描模组文件夹、列出已安装模组并加载其 AssetBundle。
  • 当前版本：1.2b 公开测试版，提供 Windows x64、Linux x86_64 与 macOS 构建。
  • MIT 许可证，无遥测，无后台服务。
  • 模组存放在模组作者自己的 GitHub 仓库中，通过 GitHub Releases 分发。客户端从不写入共享注册表——它只发起 pull request。
