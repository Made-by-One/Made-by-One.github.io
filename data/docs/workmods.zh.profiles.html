游戏配置

一个 Workmods 客户端可管理任意数量 Unity 游戏的模组。配置是一条记录 { id, name, install_dir, sdk }；注册表只保存 game_id，因此不与某台机器绑定。

  1. 打开设置 → 游戏配置，选择添加游戏。
  2. 填写小写的 Game ID（a-z、0-9、.、_、-）——必须与游戏传给 WorkmodsSDK.Initialize 的值完全一致。
  3. 设置显示名称和游戏所扫描的安装目录。留空表示 ~/DeversMods/<game_id>。
  4. 把该配置选为当前游戏。目录与已安装都会按它筛选；所有游戏显示全部内容。
文件夹 默认配置名为“Unassigned”，不可删除，并保留没有 game_id 的模组。Unity SDK 默认读取 Application.persistentDataPath/Workmods，因此要么把配置指向该文件夹，要么在 Initialize 中传入配置目录。
