Devers Workmods

Workmods is a universal mod manager for Unity games. It has three parts that share one contract — the registry entry — so a mod published once appears in every player's catalog, installs into the right folder and loads through the game's SDK without per-game work on our side.

PartWhat it does
Desktop client Python + PyQt6 app for players and authors: browse the catalog, install, update, enable or disable mods, and publish to your own GitHub repository.
Registry registry.json in the Workmods repository, rebuilt by GitHub Actions from one submission file per mod. Clients read it from raw.githubusercontent.com.
Unity SDK A single dependency-free C# file that scans the mods folder, lists installed mods and loads their AssetBundles.
  • Current version: 1.2b public beta, built for Windows x64, Linux x86_64 and macOS.
  • MIT licensed, no telemetry, no background services.
  • Mods live in the modder's own GitHub repository and are distributed through GitHub Releases. The client never writes to the shared registry — it opens a pull request.
