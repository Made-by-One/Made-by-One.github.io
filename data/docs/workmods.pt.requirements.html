Requisitos e dependências

Os builds publicados são autocontidos: Python e PyQt6 vão incluídos, então o jogador não instala mais nada. Rodar a partir do código só é necessário para desenvolvimento.

Cliente pronto

  • Windows 10/11 x64, Linux x86_64 (compilado no Ubuntu 22.04, roda em glibc mais recente) ou macOS.
  • Sem Python, sem Qt e sem privilégios de administrador. No Linux, um chmod +x uma vez.
  • Conexão de rede para o catálogo. A conta GitHub só é necessária para criar e publicar mods.

No Linux são necessárias as bibliotecas de runtime do Qt:

sudo apt-get install -y libxkbcommon0 libxkbcommon-x11-0 libfontconfig1 \
  libfreetype6 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libgl1 libegl1
Sem interface A CLI de autor (python -m workmods) não importa Qt, então funciona em máquina de build ou CI sem tela.

Unity SDK

  • C# 7.3 e Unity 2019.4 ou superior; funciona com Mono e IL2CPP, mas o carregamento de DLL em tempo de execução exige Mono.
  • Não precisa de gerenciador de pacotes nem de assembly definition — basta um arquivo em Assets/.
  • Os AssetBundles funcionam em todas as plataformas Unity; o SDK não suporta WebGL.
