要求

要求与依赖

官方构建是自包含的：Python 与 PyQt6 已打包在内，玩家无需另外安装。只有开发时才需要从源码运行。

现成客户端

  • Windows 10/11 x64、Linux x86_64（在 Ubuntu 22.04 上构建，可在更新的 glibc 上运行）或 macOS。
  • 不需要 Python、Qt 或管理员权限。Linux 上执行一次 chmod +x。
  • 需要联网读取目录。只有创建和发布模组才需要 GitHub 账号。

从源码运行

依赖版本用途
Python3.12客户端与 CLI 运行环境
PyQt6>= 6.6.0桌面界面
requests>= 2.31.0GitHub API 与下载
cryptography>= 42.0校验签名分发文件
 
git clone https://github.com/Made-by-One/Devers-Workmods.git
cd Devers-Workmods
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py

Linux 上还需要 Qt 运行时库：

sudo apt-get install -y libxkbcommon0 libxkbcommon-x11-0 libfontconfig1 \
  libfreetype6 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libgl1 libegl1
无界面 作者 CLI（python -m workmods）不导入 Qt，因此可在没有显示器的构建机或 CI 中运行。

Unity SDK

  • C# 7.3 与 Unity 2019.4 或更高版本；支持 Mono 与 IL2CPP，但运行时加载 DLL 只能在 Mono 下使用。
  • 不需要包管理器或 assembly definition——把一个文件放进 Assets/ 即可。
  • AssetBundle 在所有 Unity 平台可用；SDK 不支持 WebGL。

文件位置

路径内容
~/.devers_workmods/config.json注册表地址、语言、GitHub 令牌、游戏配置
~/.devers_workmods/profiles.json模组配置：启用集合与设置预设
~/DeversMods/<game_id>/游戏配置的默认安装目录
<mods>/.workmods-disabled/已停用的模组，SDK 会跳过
<mods>/workmods.logSDK 日志，开启文件记录时生成

可用 WORKMODS_CONFIG_DIR 移动配置目录，用 WORKMODS_REGISTRY_REPO 与 WORKMODS_REGISTRY_BRANCH 更换注册表来源。
