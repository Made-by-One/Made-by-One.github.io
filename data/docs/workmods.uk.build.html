Створення мода

Мод — це тека. Її вміст — саме те, що побачить SDK гри, плюс необов'язковий маніфест workmod.json.

neon-ui/
├── workmod.json
├── neon-ui.bundle
└── bundles/
    └── shared.bundle

Маніфест

Під час публікації клієнт вимагає лише name і version, але id, game_id та поля сумісності дають валідатору змогу відхилити пакет, який не запуститься на цільовій машині.

ПолеЗначення
idПостійний id мода. Генерується один раз і не змінюється між версіями.
game_idЦільова гра. За замовчуванням — профіль default.
name, versionНазва та версія. Тег релізу стає v<version>.
author, descriptionВільний текст для каталогу.
entry_assetНеобов'язкове ім'я асета за замовчуванням, яке може завантажити гра.
bundlesЯвні шляхи бандлів відносно кореня мода. Рекомендується, коли імена неоднозначні.
engine, sdkunity для поточного SDK.
unity_versionМінімальна версія Unity, під яку зібрано мод.
platformswindows, linux, macos, android, ios.
min_client_version, min_sdk_versionНайстаріші клієнт і SDK, які можуть встановити або завантажити мод.
tagsРядки для пошуку.
 
{
  "id": "a1b2c3d4",
  "game_id": "space-rangers",
  "name": "Neon UI",
  "version": "1.2.0",
  "author": "your-handle",
  "description": "Neon HUD replacement for the tactical screen.",
  "entry_asset": "NeonHud",
  "bundles": ["neon-ui.bundle", "bundles/shared.bundle"],
  "engine": "unity",
  "unity_version": "2021.3",
  "platforms": ["windows", "linux", "macos"],
  "tags": ["ui", "hud"]
}

Формат контенту

  • AssetBundle — рекомендований формат: працює з Mono та IL2CPP на всіх платформах. Збирайте окремий бандл під кожну платформу — між ними він не переноситься.
  • Використовуйте ChunkBasedCompression (LZ4). Бандли LZMA доводиться розпаковувати повністю, і це часта причина збоїв на Android.
  • Залежності (спільні бандли, текстури, шейдери) кладіть усередину мода. SDK завантажує всі бандли мода перед розв'язанням асетів.
  • Addressables працюють, бо збирають ті самі AssetBundle; покладіть готові файли бандлів із теки платформи.
  • DLL-збірки завантажуються лише на скриптовому бекенді Mono. Вважайте їх повністю довіреним кодом.
using UnityEditor;
using UnityEngine;

public static class WorkmodsBundleBuilder
{
    [MenuItem("Workmods/Build Mod Bundle")]
    public static void Build()
    {
        var builds = new[]
        {
            new AssetBundleBuild
            {
                assetBundleName = "neon-ui.bundle",
                assetNames = new[] { "Assets/ModContent/NeonHud.prefab" }
            }
        };

        BuildPipeline.BuildAssetBundles(
            "Build/Mod", builds,
            BuildAssetBundleOptions.ChunkBasedCompression,
            BuildTarget.StandaloneWindows64);
    }
}

CLI для авторів

Десктопного редактора достатньо, але ті самі помічники доступні з термінала та CI. Кожна команда завершується з ненульовим кодом при помилці й приймає --json для машинного виводу.

# створити теку із заповненим workmod.json
python -m workmods init neon-ui --name "Neon UI" --game space-rangers --author your-handle

# перевірити обов'язкові поля, бандли та відсутній контент
python -m workmods validate neon-ui

# зібрати релізний ZIP і надрукувати його SHA-256
python -m workmods pack neon-ui --out dist/neon-ui.zip

# знову відкрити ZIP і звірити вміст і дайджест
python -m workmods validate-package dist/neon-ui.zip --sha256 <digest>

# перевірити сумісність із конкретною ціллю
python -m workmods validate-package dist/neon-ui.zip \
  --engine unity --unity-version 2022.3 --platform windows --platform linux

У редакторі

  1. Author Studio → Вхід через GitHub, потім Новий репозиторій, щоб створити публічний репозиторій із початковим комітом (або виберіть наявний).
  2. Створити картку мода: id генерується, заповніть цільову гру, назву, версію, автора, опис, іконку й банер, теги та теку файлів. Наявний там workmod.json заповнить порожні поля.
  3. Зберегти мод пише локальну чернетку в теку встановлення гри, щоб мод можна було встановити й перевірити в грі до публікації.
Чистота Пакування пропускає .devers_meta.json, .git, __pycache__, .DS_Store, Thumbs.db і .workmods-disabled, але теку все одно варто тримати охайною.
