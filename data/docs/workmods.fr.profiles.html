Profils de jeu

Une installation de Workmods gère les mods de n'importe quel nombre de jeux Unity. Un profil est un enregistrement { id, name, install_dir, sdk } ; le registre ne stocke que le game_id, donc rien n'est lié à une machine.

  1. Ouvre Réglages → Profils de jeu et choisis Ajouter un jeu.
  2. Saisis un Game ID en minuscules (a-z, 0-9, ., _, -) — exactement la valeur que le jeu transmet à WorkmodsSDK.Initialize.
  3. Indique un nom affiché et le dossier d'installation que le jeu analyse. Vide signifie ~/DeversMods/<game_id>.
  4. Choisis le profil comme jeu actif. Catalogue et Installés se filtrent dessus ; Tous les jeux montre tout.
Dossier Le profil par défaut s'appelle « Unassigned », ne peut pas être supprimé et conserve les mods sans game_id. Le SDK Unity utilise par défaut Application.persistentDataPath/Workmods : pointe le profil vers ce dossier ou passe le dossier du profil à Initialize.
