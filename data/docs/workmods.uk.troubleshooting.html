Вирішення проблем

СимптомПричина та рішення
Каталог порожнійЗапит реєстру не пройшов або фільтр стоїть на грі без модів. Оновіть каталог і перемкніться на Усі ігри.
No mods folder at …Моди ще не встановлені або гра сканує іншу теку, ніж профіль. Задайте теку в профілі або передайте modsRoot.
Мод знайдено, але пропущеноgame_id не збігається з Initialize(gameId: …).
no AssetBundle foundУ теці немає .bundle, .unity3d або .bytes, і в маніфесті не вказані bundles.
Асет вантажиться, але префаб рожевийШейдери або текстури лежать в іншому бандлі. Кладіть залежності в мод і завантажуйте всі бандли.
Android: The archive is corruptedПерезберіть бандл зі стисненням LZ4.
GitHub API 401Токен відсутній або прострочений — вийдіть і увійдіть знову.
GitHub API 403 / 404У токена немає доступу до потрібного репозиторію або спрацював ліміт. Увійдіть знову або виберіть інший репозиторій.
GitHub API 422Тег релізу відхилено або файл завеликий. Підніміть версію й тримайте файли помітно меншими за 100 МБ.
Конфлікт pull requestІнший відкритий pull request змінює той самий файл мода. Закрийте старий і опублікуйте знову.
Мод не з'явився після mergeНе пройшло перезбирання. Відкрийте Actions → Rebuild Mod Registry у репозиторії та прочитайте лог.
У гравців Checksum mismatchAsset релізу змінився після публікації. Опублікуйте знову, щоб SHA-256 збігся.
