Devers Workmods

Workmods — універсальний менеджер модів для ігор на Unity. Він має три частини, які поділяють один контракт — запис у реєстрі: мод, опублікований один раз, з'являється в каталозі в кожного гравця, встановлюється в потрібну теку й завантажується через SDK гри без окремої роботи під кожну гру.

ЧастинаЩо робить
Десктопний клієнт Застосунок на Python + PyQt6 для гравців і авторів: перегляд каталогу, встановлення, оновлення, увімкнення й вимкнення модів, публікація у власний репозиторій на GitHub.
Реєстр registry.json у репозиторії Workmods, який GitHub Actions перезбирає з одного файлу заявки на мод. Клієнти читають його з raw.githubusercontent.com.
Unity SDK Один C#-файл без залежностей: сканує теку модів, віддає список встановлених і завантажує їхні AssetBundle.
  • Поточна версія: 1.2b — публічна бета зі збірками для Windows x64, Linux x86_64 і macOS.
  • Ліцензія MIT, без телеметрії та фонових сервісів.
  • Моди живуть у власному репозиторії моддера на GitHub і поширюються через GitHub Releases. До спільного реєстру клієнт ніколи не пише — він відкриває pull request.
