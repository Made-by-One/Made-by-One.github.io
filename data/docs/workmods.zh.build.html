制作模组

模组就是一个文件夹。其内容正是游戏 SDK 将看到的东西，外加可选的 workmod.json 清单。

neon-ui/
├── workmod.json
├── neon-ui.bundle
└── bundles/
    └── shared.bundle

清单

发布时客户端只要求 name 与 version，但 id、game_id 与兼容性字段能让校验器拒绝无法在目标环境运行的包。

字段含义
id稳定的模组 id。只生成一次，版本之间不变。
game_id目标游戏。默认使用 default 配置。
name、version名称与版本。发行标签为 v<version>。
author、description目录中显示的文本。
entry_asset可选，游戏可加载的默认资源名。
bundles相对于模组根目录的显式 bundle 路径。名称有歧义时建议填写。
engine、sdk当前 SDK 为 unity。
unity_version构建模组所用的最低 Unity 版本。
platformswindows、linux、macos、android、ios。
min_client_version、min_sdk_version可安装或加载该模组的最旧客户端与 SDK。
tags用于搜索的字符串。
 
{
  "id": "a1b2c3d4",
  "game_id": "space-rangers",
  "name": "Neon UI",
  "version": "1.2.0",
  "author": "your-handle",
  "description": "Neon HUD replacement for the tactical screen.",
  "entry_asset": "NeonHud",
  "bundles": ["neon-ui.bundle", "bundles/shared.bundle"],
  "engine": "unity",
  "unity_version": "2021.3",
  "platforms": ["windows", "linux", "macos"],
  "tags": ["ui", "hud"]
}

内容格式

  • AssetBundle 是推荐格式：在 Mono 与 IL2CPP 下均可用，覆盖所有平台。每个平台需单独构建，bundle 不能跨平台通用。
  • 请使用 ChunkBasedCompression（LZ4）。LZMA bundle 必须整体解压，是 Android 上常见的失败原因。
  • 把依赖（共享 bundle、贴图、着色器）放进模组内部。SDK 会先加载模组的所有 bundle，再解析资源。
  • Addressables 同样可用，因为它们生成的就是 AssetBundle；把平台目录中构建好的 bundle 文件一并放入。
  • DLL 只能在 Mono 脚本后端加载。请把它们视为完全可信的代码。
using UnityEditor;
using UnityEngine;

public static class WorkmodsBundleBuilder
{
    [MenuItem("Workmods/Build Mod Bundle")]
    public static void Build()
    {
        var builds = new[]
        {
            new AssetBundleBuild
            {
                assetBundleName = "neon-ui.bundle",
                assetNames = new[] { "Assets/ModContent/NeonHud.prefab" }
            }
        };

        BuildPipeline.BuildAssetBundles(
            "Build/Mod", builds,
            BuildAssetBundleOptions.ChunkBasedCompression,
            BuildTarget.StandaloneWindows64);
    }
}

作者 CLI

桌面编辑器已经够用，同样的工具也能在终端和 CI 中使用。出错时每条命令都返回非零退出码，并支持 --json 输出机器可读结果。

# 创建文件夹并生成已填写的 workmod.json
python -m workmods init neon-ui --name "Neon UI" --game space-rangers --author your-handle

# 检查必填字段、bundle 与缺失内容
python -m workmods validate neon-ui

# 构建发行 ZIP 并输出其 SHA-256
python -m workmods pack neon-ui --out dist/neon-ui.zip

# 重新打开 ZIP，核对内容与摘要
python -m workmods validate-package dist/neon-ui.zip --sha256 <digest>

# 针对具体目标检查兼容性
python -m workmods validate-package dist/neon-ui.zip \
  --engine unity --unity-version 2022.3 --platform windows --platform linux

在编辑器中

  1. Author Studio → 通过 GitHub 登录，然后新建仓库创建带初始提交的公开仓库（或选择已有仓库）。
  2. 创建模组条目：id 会自动生成，填写目标游戏、名称、版本、作者、描述、图标与横幅、标签和文件文件夹。该文件夹中的 workmod.json 会补全空白字段。
  3. 保存模组会把本地草稿写入游戏的安装目录，便于在发布前安装并在游戏中测试。
保持整洁 打包会跳过 .devers_meta.json、.git、__pycache__、.DS_Store、Thumbs.db 与 .workmods-disabled，但仍建议保持文件夹干净。
