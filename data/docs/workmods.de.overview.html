Devers Workmods

Workmods ist ein universeller Mod-Manager für Unity-Spiele. Drei Teile teilen einen Vertrag — den Registry-Eintrag: Ein einmal veröffentlichter Mod erscheint im Katalog jedes Spielers, landet im richtigen Ordner und wird über das SDK des Spiels geladen, ohne Zusatzarbeit pro Spiel.

TeilWas er tut
Desktop-Client App auf Python + PyQt6 für Spieler und Autoren: Katalog durchsuchen, installieren, aktualisieren, Mods aktivieren oder deaktivieren und in ein eigenes GitHub-Repository veröffentlichen.
Registry registry.json im Workmods-Repository, das GitHub Actions aus je einer Einreichungsdatei pro Mod neu baut. Clients lesen sie von raw.githubusercontent.com.
Unity SDK Eine einzige C#-Datei ohne Abhängigkeiten: scannt den Mod-Ordner, listet installierte Mods und lädt ihre AssetBundles.
  • Aktuelle Version: 1.2b, öffentliche Beta mit Builds für Windows x64, Linux x86_64 und macOS.
  • MIT-Lizenz, keine Telemetrie, keine Hintergrunddienste.
  • Mods liegen im eigenen GitHub-Repository des Modders und werden über GitHub Releases verteilt. In die geteilte Registry schreibt der Client nie — er öffnet einen Pull Request.
