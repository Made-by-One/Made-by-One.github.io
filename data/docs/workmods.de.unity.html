Für Spieleentwickler

Unity SDK

unity-sdk/WorkmodsSDK.cs ist eine einzige abhängigkeitsfreie C#-Datei: Sie scannt einen Mod-Ordner, gibt installierte Mods aus und lädt deren Assets.

  1. Kopiere WorkmodsSDK.cs in dein Projekt, etwa nach Assets/Workmods/.
  2. Entscheide, wo Mods liegen. Der Client nutzt standardmäßig ~/DeversMods/<game_id>, das SDK Application.persistentDataPath/Workmods. Richte das Spielprofil auf den Ordner, den dein Spiel scannt, oder übergib modsRoot bei der Initialisierung.
  3. Einmal initialisieren, dann nach Mod-ID und Assetnamen laden.
using Workmods;
using UnityEngine;

public class Mods : MonoBehaviour
{
    private void Awake()
    {
        WorkmodsSDK.Initialize(
            modsRoot: null,            // null → persistentDataPath/Workmods
            gameId: "space-rangers",   // Mods für andere Spiele ablehnen
            verboseLogging: true,
            writeLogToFile: true);     // <modsRoot>/workmods.log
    }
}

// Prefab aus einem installierten Mod laden
var prefab = WorkmodsSDK.LoadAsset<GameObject>("a1b2c3d4", "NeonHud");
if (prefab != null) Instantiate(prefab);
MemberBeschreibung
Initialize(...)Scannt den Ordner. Mehrfach aufrufbar.
Rescan()Ordner nach einer Installation im Spiel neu lesen.
GetInstalledMods()Installierte Mods, gefiltert nach gameId.
GetInstalledMod(id), IsInstalled(id)Nachschlagehelfer, ohne Groß-/Kleinschreibung.
LoadAssetBundle(id, name)UnityEngine.Object oder null; der Grund wird geloggt.
LoadAsset<T>(id, name)Typisierte Variante, etwa <GameObject>.
LoadBundles(mod)Alle Bundles eines Mods laden und cachen, inklusive Abhängigkeiten.
TryLoadAssembly(id, out asm)Nur Mono; liefert unter IL2CPP false.
UnloadAssetBundle(id), UnloadAll()Bundles entladen — vorher Instanzen zerstören.
WorkmodsLog.OnLogSDK-Meldungen in den eigenen Logger leiten.
  • Alles läuft im Hauptthread; lade Bundles nicht aus Worker-Threads.
  • Deaktivierte Mods liegen in .workmods-disabled/ und werden beim nächsten Scan automatisch übersprungen.
  • Windows, macOS und Linux standalone werden voll unterstützt; Android braucht LZ4-Bundles; iOS funktioniert mit AssetBundles, die die eigene Oberfläche installiert; Konsolen brauchen plattformspezifisches Packaging.
  • WebGL wird nicht unterstützt: kein synchroner Dateizugriff, ein asynchroner Loader wäre nötig.
