Solución de problemas

SíntomaCausa y solución
El catálogo está vacíoFalló la petición del registro o el filtro apunta a un juego sin mods. Actualiza y cambia a Todos los juegos.
No mods folder at …No hay mods instalados o el juego escanea otra carpeta que el perfil. Ajusta la carpeta del perfil o pasa modsRoot.
El mod se detecta pero se omiteEl game_id no coincide con Initialize(gameId: …).
no AssetBundle foundLa carpeta no tiene .bundle, .unity3d ni .bytes y el manifiesto no lista bundles.
El asset carga pero el prefab sale rosaShaders o texturas están en otro bundle. Incluye las dependencias en el mod y carga todos los bundles.
Android: The archive is corruptedRecompila el bundle con compresión LZ4.
GitHub API 401Token ausente o caducado: cierra sesión y vuelve a entrar.
GitHub API 403 / 404El token no tiene acceso al repositorio o se alcanzó un límite. Vuelve a iniciar sesión o elige otro repositorio.
GitHub API 422Etiqueta de release rechazada o archivo demasiado grande. Sube la versión y mantén los archivos muy por debajo de 100 MB.
Conflicto de pull requestOtro pull request abierto modifica el mismo archivo del mod. Cierra el antiguo y publica de nuevo.
El mod no aparece tras el mergeFalló la reconstrucción. Abre Actions → Rebuild Mod Registry en el repositorio y lee el log.
Los jugadores ven Checksum mismatchEl asset del release cambió tras publicar. Publica de nuevo para que el SHA-256 coincida.
