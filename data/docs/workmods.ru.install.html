Установка

Установка и первый запуск

  1. Откройте страницу Releases и скачайте архив для своей системы: Workmods-windows-x86_64.zip, Workmods-linux-x86_64.tar.gz или Workmods-macos.zip.
  2. Распакуйте куда угодно. Сборка переносимая: состояние хранится в домашней папке, а не рядом с исполняемым файлом.
  3. Запустите Workmods.exe в Windows, ./Workmods в Linux (после chmod +x Workmods) или Workmods.app в macOS.
  4. При первом запуске клиент загружает реестр, определяет язык системы и создаёт профиль игры по умолчанию.

Интерфейс переведён на шесть языков — английский, русский, немецкий, испанский, французский и китайский — и переключается в настройках мгновенно. До входа через GitHub каталог работает в режиме чтения; для установки и обновления модов аккаунт не нужен.

Обновления Настройки → Обновления приложения проверяют GitHub Releases, сверяют SHA256SUMS и отсоединённую подпись, если она опубликована, сохраняют копию предыдущего исполняемого файла и умеют откатиться, если обновление не применилось.
