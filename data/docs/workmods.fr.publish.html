Publication

Publier, c'est une pull request. Il faut un compte GitHub ; pas besoin de connaître git, d'avoir un droit d'écriture sur le registre ni un serveur.

  1. Le client compresse le dossier du mod en ZIP (racine = le dossier lui-même, sans dossier englobant) et calcule son SHA-256.
  2. Tous les fichiers, plus icon.png / banner.png, sont commités dans ton dépôt de mod.
  3. Une release v<version> est créée et <modId>.zip y est attaché.
  4. Une pull request ajoute submissions/<game_id>/<mod_id>.json avec les métadonnées, l'URL de téléchargement, l'empreinte et ton identifiant.
  5. Validate Submission vérifie le chemin, l'id, la version, le hash et l'URL de release. Un mainteneur relit et fusionne.
  6. Rebuild Mod Registry régénère registry.json à partir de toutes les soumissions. Les joueurs voient le mod après la prochaine actualisation du catalogue.

Versions et mises à jour

  • La version est libre, sans espaces ni barres obliques : 1.0.0, 1.2.0, 2.0.0-beta.1. Le tag est toujours v<version>.
  • Republier la même version réutilise la release et remplace son asset.
  • Pour mettre à jour, modifie le mod, incrémente la version et publie : la pull request met à jour le même fichier de soumission, les joueurs gardent une seule entrée. Ferme d'abord une pull request encore ouverte sur ce mod.
  • Unpublish ouvre une pull request qui supprime le fichier de soumission. Le dépôt, les fichiers et les releases restent en ligne, et les joueurs existants gardent leur copie locale.

Limites

LimiteValeur
Fichier unique via l'API GitHub ContentsBien en dessous de 100 Mo — l'API n'est pas un CDN
ZIP de releaseJusqu'à 2 Go
Id du mod[a-z0-9][a-z0-9._-]{1,63}
TagsListe de 20 chaînes courtes au maximum
Empreinte64 caractères hexadécimaux minuscules, vérifiés par le client après téléchargement

Avant de publier : le game_id correspond exactement au jeu, les bundles sont compilés pour la bonne plateforme, la version est incrémentée et l'id du mod inchangé, le mod a été testé en local, et le dossier ne contient ni secret ni contenu sans licence.
