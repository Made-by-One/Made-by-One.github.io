Requisitos y dependencias

Las compilaciones publicadas son autocontenidas: Python y PyQt6 van incluidos, así que el jugador no instala nada más. Ejecutar desde el código solo es necesario para desarrollar.

Cliente ya compilado

  • Windows 10/11 x64, Linux x86_64 (compilado en Ubuntu 22.04, funciona con glibc más reciente) o macOS.
  • No requiere Python, ni Qt, ni permisos de administrador. En Linux, un chmod +x una vez.
  • Conexión de red para el catálogo. La cuenta de GitHub solo hace falta para crear y publicar mods.

En Linux hacen falta las bibliotecas de entorno de Qt:

sudo apt-get install -y libxkbcommon0 libxkbcommon-x11-0 libfontconfig1 \
  libfreetype6 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libgl1 libegl1
Sin interfaz La CLI para autores (python -m workmods) no importa Qt, así que funciona en una máquina de compilación o en CI sin pantalla.

Unity SDK

  • C# 7.3 y Unity 2019.4 o superior; funciona con Mono e IL2CPP, pero cargar DLL en tiempo de ejecución requiere Mono.
  • No necesita gestor de paquetes ni assembly definition: basta con un archivo en Assets/.
  • Los AssetBundles funcionan en todas las plataformas de Unity; el SDK no admite WebGL.

La carpeta de configuración se puede mover con WORKMODS_CONFIG_DIR; el origen del registro, con WORKMODS_REGISTRY_REPO y WORKMODS_REGISTRY_BRANCH.
