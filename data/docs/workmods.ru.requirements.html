Требования и зависимости

Релизные сборки самодостаточны: Python и PyQt6 уже внутри, игроку ничего доустанавливать не нужно. Запуск из исходников нужен только для разработки.

Готовая сборка клиента

  • Windows 10/11 x64, Linux x86_64 (собрано на Ubuntu 22.04, работает на более новом glibc) или macOS.
  • Python, Qt и права администратора не нужны. На Linux один раз chmod +x.
  • Сеть для загрузки каталога. Аккаунт GitHub нужен только для создания и публикации модов.

На Linux нужны библиотеки окружения Qt:

sudo apt-get install -y libxkbcommon0 libxkbcommon-x11-0 libfontconfig1 \
  libfreetype6 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libgl1 libegl1
Без интерфейса CLI для авторов (python -m workmods) не импортирует Qt, поэтому работает на сборочной машине и в CI без дисплея.

Unity SDK

  • C# 7.3 и Unity 2019.4 или новее; работает с Mono и IL2CPP, но загрузка DLL во время выполнения — только на Mono.
  • Не нужны ни пакетный менеджер, ни assembly definition — достаточно одного файла в Assets/.
  • AssetBundle работают на всех платформах Unity; WebGL SDK не поддерживает.

Каталог конфигурации можно перенести через WORKMODS_CONFIG_DIR, источник реестра — через WORKMODS_REGISTRY_REPO и WORKMODS_REGISTRY_BRANCH.
