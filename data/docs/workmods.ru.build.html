Создание мода

Мод — это папка. Её содержимое — ровно то, что увидит SDK игры, плюс необязательный манифест workmod.json.

neon-ui/
├── workmod.json
├── neon-ui.bundle
└── bundles/
    └── shared.bundle

Манифест

При публикации клиент требует только name и version, но id, game_id и поля совместимости позволяют валидатору отклонить пакет, который не запустится на целевой машине.

ПолеЗначение
idПостоянный id мода. Генерируется один раз и не меняется между версиями.
game_idЦелевая игра. По умолчанию — профиль default.
name, versionНазвание и версия. Тег релиза становится v<version>.
author, descriptionСвободный текст для каталога.
entry_assetНеобязательное имя ассета по умолчанию, которое может загрузить игра.
bundlesЯвные пути бандлов относительно корня мода. Рекомендуется, когда имена неоднозначны.
engine, sdkunity для текущего SDK.
unity_versionМинимальная версия Unity, под которую собран мод.
platformswindows, linux, macos, android, ios.
min_client_version, min_sdk_versionСамые старые клиент и SDK, которые могут установить или загрузить мод.
tagsСтроки для поиска.
 
{
  "id": "a1b2c3d4",
  "game_id": "space-rangers",
  "name": "Neon UI",
  "version": "1.2.0",
  "author": "your-handle",
  "description": "Neon HUD replacement for the tactical screen.",
  "entry_asset": "NeonHud",
  "bundles": ["neon-ui.bundle", "bundles/shared.bundle"],
  "engine": "unity",
  "unity_version": "2021.3",
  "platforms": ["windows", "linux", "macos"],
  "tags": ["ui", "hud"]
}

Формат контента

  • AssetBundle — рекомендуемый формат: работает с Mono и IL2CPP на всех платформах. Собирайте отдельный бандл под каждую платформу — между ними он не переносится.
  • Используйте ChunkBasedCompression (LZ4). Бандлы LZMA приходится распаковывать целиком, и это частая причина сбоев на Android.
  • Зависимости (общие бандлы, текстуры, шейдеры) кладите внутрь мода. SDK загружает все бандлы мода перед разрешением ассетов.
  • Addressables работают, потому что собирают те же AssetBundle; положите готовые файлы бандлов из папки платформы.
  • DLL-сборки загружаются только на скриптовом бэкенде Mono. Считайте их полностью доверенным кодом.
using UnityEditor;
using UnityEngine;

public static class WorkmodsBundleBuilder
{
    [MenuItem("Workmods/Build Mod Bundle")]
    public static void Build()
    {
        var builds = new[]
        {
            new AssetBundleBuild
            {
                assetBundleName = "neon-ui.bundle",
                assetNames = new[] { "Assets/ModContent/NeonHud.prefab" }
            }
        };

        BuildPipeline.BuildAssetBundles(
            "Build/Mod", builds,
            BuildAssetBundleOptions.ChunkBasedCompression,
            BuildTarget.StandaloneWindows64);
    }
}

CLI для авторов

Десктопного редактора достаточно, но те же помощники доступны из терминала и CI. Каждая команда завершается с ненулевым кодом при ошибке и принимает --json для машинного вывода.

# создать папку с заполненным workmod.json
python -m workmods init neon-ui --name "Neon UI" --game space-rangers --author your-handle

# проверить обязательные поля, бандлы и отсутствующий контент
python -m workmods validate neon-ui

# собрать релизный ZIP и напечатать его SHA-256
python -m workmods pack neon-ui --out dist/neon-ui.zip

# заново открыть ZIP и сверить содержимое и дайджест
python -m workmods validate-package dist/neon-ui.zip --sha256 <digest>

# проверить совместимость с конкретной целью
python -m workmods validate-package dist/neon-ui.zip \
  --engine unity --unity-version 2022.3 --platform windows --platform linux

В редакторе

  1. Author Studio → Вход через GitHub, затем Новый репозиторий, чтобы создать публичный репозиторий с начальным коммитом (или выберите существующий).
  2. Создать карточку мода: id генерируется, заполните целевую игру, название, версию, автора, описание, иконку и баннер, теги и папку файлов. Лежащий там workmod.json заполнит пустые поля.
  3. Сохранить мод пишет локальный черновик в папку установки игры, чтобы мод можно было поставить и проверить в игре до публикации.
Чистота Упаковка пропускает .devers_meta.json, .git, __pycache__, .DS_Store, Thumbs.db и .workmods-disabled, но папку всё равно стоит держать в порядке.
