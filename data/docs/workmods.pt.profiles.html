Perfis de jogo

Uma instalação do Workmods gerencia mods de qualquer número de jogos Unity. Um perfil é um registro { id, name, install_dir, sdk }; o registro compartilhado guarda apenas o game_id, então nada fica preso a uma máquina.

  1. Abra Configurações → Perfis de jogo e escolha Adicionar jogo.
  2. Informe um Game ID em minúsculas (a-z, 0-9, ., _, -) — exatamente o valor que o jogo passa para WorkmodsSDK.Initialize.
  3. Defina um nome de exibição e a pasta de instalação que o jogo varre. Vazio significa ~/DeversMods/<game_id>.
  4. Escolha o perfil como jogo ativo. Catálogo e Instalados filtram por ele; Todos os jogos mostra tudo.
Pasta O perfil padrão se chama “Unassigned”, não pode ser removido e mantém os mods sem game_id. O SDK do Unity usa por padrão Application.persistentDataPath/Workmods: aponte o perfil para essa pasta ou passe a pasta do perfil para Initialize.
