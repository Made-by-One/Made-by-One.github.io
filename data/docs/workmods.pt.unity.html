Para desenvolvedores de jogos

Unity SDK

unity-sdk/WorkmodsSDK.cs é um único arquivo C# sem dependências que varre uma pasta de mods, expõe os instalados e carrega seus assets.

  1. Copie WorkmodsSDK.cs para o projeto, por exemplo em Assets/Workmods/.
  2. Decida onde ficam os mods. O cliente usa ~/DeversMods/<game_id> por padrão; o SDK usa Application.persistentDataPath/Workmods. Aponte o perfil do jogo para a pasta que seu jogo varre ou passe modsRoot na inicialização.
  3. Inicialize uma vez e carregue por id do mod e nome do asset.
using Workmods;
using UnityEngine;

public class Mods : MonoBehaviour
{
    private void Awake()
    {
        WorkmodsSDK.Initialize(
            modsRoot: null,            // null → persistentDataPath/Workmods
            gameId: "space-rangers",   // recusar mods de outros jogos
            verboseLogging: true,
            writeLogToFile: true);     // <modsRoot>/workmods.log
    }
}

// carregar um prefab de um mod instalado
var prefab = WorkmodsSDK.LoadAsset<GameObject>("a1b2c3d4", "NeonHud");
if (prefab != null) Instantiate(prefab);
MembroDescrição
Initialize(...)Varre a pasta. Pode ser chamado repetidamente.
Rescan()Relê a pasta após uma instalação no jogo.
GetInstalledMods()Mods instalados, filtrados por gameId.
GetInstalledMod(id), IsInstalled(id)Buscas auxiliares, sem diferenciar maiúsculas.
LoadAssetBundle(id, name)UnityEngine.Object ou null; registra o motivo da falha.
LoadAsset<T>(id, name)Variante tipada, por exemplo <GameObject>.
LoadBundles(mod)Carrega e cacheia todos os bundles de um mod, com dependências.
TryLoadAssembly(id, out asm)Só Mono; retorna false no IL2CPP.
UnloadAssetBundle(id), UnloadAll()Descarrega bundles; destrua as instâncias antes.
WorkmodsLog.OnLogEnvia as mensagens do SDK para o seu próprio logger.
  • Tudo roda na thread principal; não carregue bundles de threads de trabalho.
  • Mods desativados ficam em .workmods-disabled/ e são ignorados na próxima varredura.
  • Windows, macOS e Linux standalone têm suporte completo; Android exige bundles LZ4; iOS funciona com AssetBundles instalados pela sua interface; consoles exigem empacotamento específico.
  • WebGL não é suportado: não há acesso síncrono a arquivos e seria necessário um carregador assíncrono.
