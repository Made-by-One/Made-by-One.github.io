Devers Workmods

Workmods — универсальный менеджер модов для игр на Unity. У него три части, которые делят один контракт — запись в реестре: мод, опубликованный один раз, появляется в каталоге у каждого игрока, ставится в нужную папку и загружается через SDK игры без отдельной работы под каждую игру.

ЧастьЧто делает
Десктоп-клиент Приложение на Python + PyQt6 для игроков и авторов: просмотр каталога, установка, обновление, включение и отключение модов, публикация в собственный репозиторий на GitHub.
Реестр registry.json в репозитории Workmods, пересобирается через GitHub Actions из одного файла заявки на мод. Клиенты читают его с raw.githubusercontent.com.
Unity SDK Один C#-файл без зависимостей: сканирует папку модов, отдаёт список установленных и загружает их AssetBundle.
  • Текущая версия: 1.2b — публичная бета со сборками для Windows x64, Linux x86_64 и macOS.
  • Лицензия MIT, без телеметрии и фоновых сервисов.
  • Моды живут в собственном репозитории моддера на GitHub и распространяются через GitHub Releases. В общий реестр клиент никогда не пишет — он открывает pull request.
