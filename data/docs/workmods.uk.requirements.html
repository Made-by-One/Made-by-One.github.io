Вимоги

Вимоги та залежності

Релізні збірки самодостатні: Python і PyQt6 уже всередині, гравцеві нічого до встановлювати. Запуск із джерел потрібен лише для розробки.

Готова збірка клієнта

  • Windows 10/11 x64, Linux x86_64 (зібрано на Ubuntu 22.04, працює на новішому glibc) або macOS.
  • Python, Qt і права адміністратора не потрібні. На Linux один раз chmod +x.
  • Мережа для завантаження каталогу. Акаунт GitHub потрібен лише для створення й публікації модів.

На Linux потрібні бібліотеки оточення Qt:

sudo apt-get install -y libxkbcommon0 libxkbcommon-x11-0 libfontconfig1 \
  libfreetype6 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libgl1 libegl1
Без інтерфейсу CLI для авторів (python -m workmods) не імпортує Qt, тому працює на складальній машині та в CI без дисплея.

Unity SDK

  • C# 7.3 і Unity 2019.4 або новіше; працює з Mono та IL2CPP, але завантаження DLL під час виконання — лише на Mono.
  • Не потрібні ні пакетний менеджер, ні assembly definition — достатньо одного файлу в Assets/.
  • AssetBundle працюють на всіх платформах Unity; WebGL SDK не підтримує.
