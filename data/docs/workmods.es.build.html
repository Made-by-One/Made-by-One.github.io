Autoría

Crear un mod

Un mod es una carpeta. Su contenido es exactamente lo que verá el SDK del juego, más un manifiesto opcional workmod.json.

neon-ui/
├── workmod.json
├── neon-ui.bundle
└── bundles/
    └── shared.bundle

El manifiesto

Al publicar, el cliente solo exige name y version, pero id, game_id y los campos de compatibilidad permiten que el validador rechace un paquete que no puede ejecutarse en el destino.

CampoSignificado
idId estable del mod. Se genera una vez y no cambia entre versiones.
game_idJuego destino. Por defecto, el perfil default.
name, versionNombre y versión. La etiqueta del release pasa a ser v<version>.
author, descriptionTexto libre que se muestra en el catálogo.
entry_assetNombre de asset por defecto opcional que el juego puede cargar.
bundlesRutas explícitas de bundles relativas a la raíz del mod. Recomendado cuando los nombres son ambiguos.
engine, sdkunity para el SDK actual.
unity_versionVersión mínima de Unity para la que se compiló el mod.
platformswindows, linux, macos, android, ios.
min_client_version, min_sdk_versionCliente y SDK más antiguos que pueden instalar o cargar el mod.
tagsCadenas para la búsqueda.
 
{
  "id": "a1b2c3d4",
  "game_id": "space-rangers",
  "name": "Neon UI",
  "version": "1.2.0",
  "author": "your-handle",
  "description": "Neon HUD replacement for the tactical screen.",
  "entry_asset": "NeonHud",
  "bundles": ["neon-ui.bundle", "bundles/shared.bundle"],
  "engine": "unity",
  "unity_version": "2021.3",
  "platforms": ["windows", "linux", "macos"],
  "tags": ["ui", "hud"]
}

Formato del contenido

  • Los AssetBundles son el formato recomendado: funcionan con Mono e IL2CPP en todas las plataformas. Compila un bundle por plataforma, porque no son portables entre ellas.
  • Usa ChunkBasedCompression (LZ4). Los bundles LZMA se descomprimen completos y son una causa habitual de fallos en Android.
  • Incluye las dependencias (bundles compartidos, texturas, shaders) dentro del mod. El SDK carga todos los bundles del mod antes de resolver assets.
  • Los Addressables funcionan porque generan AssetBundles; incluye los archivos de bundle compilados de la carpeta de la plataforma.
  • Las DLL solo se cargan con el backend de scripts Mono. Trátalas como código totalmente de confianza.
using UnityEditor;
using UnityEngine;

public static class WorkmodsBundleBuilder
{
    [MenuItem("Workmods/Build Mod Bundle")]
    public static void Build()
    {
        var builds = new[]
        {
            new AssetBundleBuild
            {
                assetBundleName = "neon-ui.bundle",
                assetNames = new[] { "Assets/ModContent/NeonHud.prefab" }
            }
        };

        BuildPipeline.BuildAssetBundles(
            "Build/Mod", builds,
            BuildAssetBundleOptions.ChunkBasedCompression,
            BuildTarget.StandaloneWindows64);
    }
}

CLI para autores

El editor de escritorio es suficiente, pero las mismas utilidades están disponibles en la terminal y en CI. Cada comando sale con código distinto de cero si hay errores y acepta --json para salida legible por máquina.

# crear una carpeta con un workmod.json rellenado
python -m workmods init neon-ui --name "Neon UI" --game space-rangers --author your-handle

# comprobar campos obligatorios, bundles y contenido que falta
python -m workmods validate neon-ui

# compilar el ZIP de release e imprimir su SHA-256
python -m workmods pack neon-ui --out dist/neon-ui.zip

# reabrir el ZIP y verificar contenido y digest
python -m workmods validate-package dist/neon-ui.zip --sha256 <digest>

# comprobar compatibilidad con un destino concreto
python -m workmods validate-package dist/neon-ui.zip \
  --engine unity --unity-version 2022.3 --platform windows --platform linux

En el editor

  1. Author Studio → Iniciar sesión con GitHub y luego Nuevo repositorio para crear un repositorio público con un commit inicial (o elige uno existente).
  2. Crear la ficha del mod: el id se genera solo; rellena juego destino, nombre, versión, autor, descripción, icono y banner, etiquetas y carpeta de archivos. Un workmod.json en esa carpeta rellena los campos vacíos.
  3. Guardar mod escribe un borrador local en la carpeta de instalación del juego, para poder instalarlo y probarlo en el juego antes de publicar.
Limpieza El empaquetado omite .devers_meta.json, .git, __pycache__, .DS_Store, Thumbs.db y .workmods-disabled, pero conviene mantener la carpeta ordenada igualmente.
