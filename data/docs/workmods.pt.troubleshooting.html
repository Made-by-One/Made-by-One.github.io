Solução de problemas

SintomaCausa e solução
O catálogo está vazioA requisição do registro falhou ou o filtro está num jogo sem mods. Atualize e mude para Todos os jogos.
No mods folder at …Nada instalado ou o jogo varre outra pasta que não o perfil. Ajuste a pasta do perfil ou passe modsRoot.
Mod encontrado mas ignoradogame_id não corresponde a Initialize(gameId: …).
no AssetBundle foundA pasta não tem .bundle, .unity3d nem .bytes, e o manifesto não lista bundles.
O asset carrega, mas o prefab fica rosaShaders ou texturas estão em outro bundle. Inclua as dependências no mod e carregue todos os bundles.
Android: The archive is corruptedRecompile o bundle com compressão LZ4.
GitHub API 401Token ausente ou expirado — saia e entre novamente.
GitHub API 403 / 404O token não tem acesso ao repositório ou um limite foi atingido. Entre de novo ou escolha outro repositório.
GitHub API 422Tag de release recusada ou arquivo grande demais. Suba a versão e mantenha os arquivos bem abaixo de 100 MB.
Conflito de pull requestOutro pull request aberto altera o mesmo arquivo do mod. Feche o antigo e publique de novo.
O mod não aparece após o mergeA reconstrução falhou. Abra Actions → Rebuild Mod Registry no repositório e leia o log.
Checksum mismatch para os jogadoresO asset do release mudou após a publicação. Publique de novo para o SHA-256 bater.
