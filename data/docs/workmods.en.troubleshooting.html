Troubleshooting

SymptomCause and fix
Catalog is emptyRegistry request failed or the filter is set to a game without mods. Refresh, then switch to All games.
No mods folder at …Nothing installed yet, or the game scans a different folder than the profile. Set the profile directory or pass modsRoot.
Mod discovered but skippedgame_id mismatch with Initialize(gameId: …).
no AssetBundle foundThe folder has no .bundle, .unity3d or .bytes file and the manifest does not list bundles.
Asset loads but prefab is pinkShaders or textures sit in another bundle. Ship dependencies inside the mod and load all bundles.
Android The archive is corruptedRebuild the bundle with LZ4 compression.
GitHub API 401Token missing or expired — log out and log in again.
GitHub API 403 / 404Token lacks access to the target repository, or a rate limit. Re-login or pick another repository.
GitHub API 422Release tag rejected or a file too large. Bump the version and keep files well below 100 MB.
Pull request conflictsAnother open pull request changes the same mod file. Close the older one and publish again.
Mod never appears after mergeThe rebuild action failed. Open the repository's Actions → Rebuild Mod Registry and read the log.
Checksum mismatch for playersThe release asset changed after publishing. Publish again so the SHA-256 matches.
