Erstellen

Einen Mod bauen

Ein Mod ist ein Ordner. Sein Inhalt ist genau das, was das SDK des Spiels sieht, plus ein optionales Manifest workmod.json.

neon-ui/
├── workmod.json
├── neon-ui.bundle
└── bundles/
    └── shared.bundle

Das Manifest

Beim Veröffentlichen verlangt der Client nur name und version. id, game_id und die Kompatibilitätsfelder erlauben dem Validator jedoch, ein Paket abzulehnen, das auf dem Ziel nicht laufen kann.

FeldBedeutung
idStabile Mod-ID. Einmal erzeugt, zwischen Versionen unverändert.
game_idZielspiel. Standard ist das Profil default.
name, versionAnzeigename und Version. Das Release-Tag wird v<version>.
author, descriptionFreitext für den Katalog.
entry_assetOptionaler Standard-Assetname, den das Spiel laden kann.
bundlesExplizite Bundle-Pfade relativ zum Mod-Ordner. Empfohlen bei mehrdeutigen Namen.
engine, sdkunity für das aktuelle SDK.
unity_versionMinimale Unity-Version, für die der Mod gebaut wurde.
platformswindows, linux, macos, android, ios.
min_client_version, min_sdk_versionÄltester Client und ältestes SDK, das den Mod installieren oder laden kann.
tagsSuchbare Zeichenketten.
 
{
  "id": "a1b2c3d4",
  "game_id": "space-rangers",
  "name": "Neon UI",
  "version": "1.2.0",
  "author": "your-handle",
  "description": "Neon HUD replacement for the tactical screen.",
  "entry_asset": "NeonHud",
  "bundles": ["neon-ui.bundle", "bundles/shared.bundle"],
  "engine": "unity",
  "unity_version": "2021.3",
  "platforms": ["windows", "linux", "macos"],
  "tags": ["ui", "hud"]
}

Inhaltsformat

  • AssetBundles sind das empfohlene Format: Sie laufen mit Mono und IL2CPP auf allen Plattformen. Baue ein Bundle pro Plattform — zwischen ihnen ist es nicht portabel.
  • Nutze ChunkBasedCompression (LZ4). LZMA-Bundles müssen vollständig entpackt werden und sind eine häufige Ursache für Android-Fehler.
  • Abhängigkeiten (gemeinsame Bundles, Texturen, Shader) gehören in den Mod. Das SDK lädt alle Bundles eines Mods, bevor es Assets auflöst.
  • Addressables funktionieren, weil sie AssetBundles erzeugen; lege die fertigen Bundle-Dateien aus dem Plattformordner dazu.
  • DLLs werden nur mit dem Mono-Scripting-Backend geladen. Behandle sie als vollständig vertrauenswürdigen Code.
using UnityEditor;
using UnityEngine;

public static class WorkmodsBundleBuilder
{
    [MenuItem("Workmods/Build Mod Bundle")]
    public static void Build()
    {
        var builds = new[]
        {
            new AssetBundleBuild
            {
                assetBundleName = "neon-ui.bundle",
                assetNames = new[] { "Assets/ModContent/NeonHud.prefab" }
            }
        };

        BuildPipeline.BuildAssetBundles(
            "Build/Mod", builds,
            BuildAssetBundleOptions.ChunkBasedCompression,
            BuildTarget.StandaloneWindows64);
    }
}

Autoren-CLI

Der Desktop-Editor reicht aus, dieselben Helfer gibt es aber auch im Terminal und in CI. Jeder Befehl endet bei Fehlern mit einem Exit-Code ungleich null und akzeptiert --json für maschinenlesbare Ausgabe.

# Ordner mit ausgefüllter workmod.json anlegen
python -m workmods init neon-ui --name "Neon UI" --game space-rangers --author your-handle

# Pflichtfelder, Bundles und fehlende Inhalte prüfen
python -m workmods validate neon-ui

# Release-ZIP bauen und SHA-256 ausgeben
python -m workmods pack neon-ui --out dist/neon-ui.zip

# ZIP erneut öffnen, Inhalt und Digest prüfen
python -m workmods validate-package dist/neon-ui.zip --sha256 <digest>

# Kompatibilität gegen ein konkretes Ziel prüfen
python -m workmods validate-package dist/neon-ui.zip \
  --engine unity --unity-version 2022.3 --platform windows --platform linux

Im Editor

  1. Author Studio → Login via GitHub, dann Neues Repo, um ein öffentliches Repository mit Initial-Commit anzulegen (oder ein vorhandenes wählen).
  2. Erstellen öffnet den Mod-Eintrag: Die ID wird erzeugt; fülle Zielspiel, Name, Version, Autor, Beschreibung, Icon und Banner, Tags und den Dateiordner. Eine workmod.json in diesem Ordner füllt leere Felder.
  3. Mod speichern schreibt einen lokalen Entwurf in den Installationsordner des Spiels, damit du ihn vor dem Veröffentlichen im Spiel testen kannst.
Sauber halten Das Packen überspringt .devers_meta.json, .git, __pycache__, .DS_Store, Thumbs.db und .workmods-disabled — trotzdem sollte der Ordner ordentlich bleiben.
