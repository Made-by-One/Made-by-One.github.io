Prérequis et dépendances

Les builds publiés sont autonomes : Python et PyQt6 sont inclus, le joueur n'installe rien d'autre. Lancer depuis les sources ne sert qu'au développement.

Client précompilé

  • Windows 10/11 x64, Linux x86_64 (compilé sur Ubuntu 22.04, fonctionne avec un glibc plus récent) ou macOS.
  • Ni Python, ni Qt, ni droits administrateur. Sous Linux, un chmod +x une fois.
  • Une connexion réseau pour le catalogue. Un compte GitHub n'est requis que pour créer et publier des mods.

git clone https://github.com/Made-by-One/Devers-Workmods.git
cd Devers-Workmods
python -m venv .venv
source .venv/bin/activate        # Windows : .venv\Scripts\activate
pip install -r requirements.txt
python main.py

Sous Linux, les bibliothèques d'exécution de Qt sont nécessaires :

sudo apt-get install -y libxkbcommon0 libxkbcommon-x11-0 libfontconfig1 \
  libfreetype6 libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 \
  libxcb-shape0 libxcb-xinerama0 libgl1 libegl1
Sans interface La CLI d'auteur (python -m workmods) n'importe pas Qt : elle fonctionne sur une machine de build ou en CI, sans écran.

Unity SDK

  • C# 7.3 et Unity 2019.4 ou plus récent ; compatible Mono et IL2CPP, mais le chargement de DLL à l'exécution demande Mono.
  • Ni gestionnaire de paquets ni assembly definition : un fichier dans Assets/ suffit.
  • Les AssetBundles fonctionnent sur toutes les plateformes Unity ; le SDK ne prend pas en charge WebGL.

Le dossier de configuration se déplace avec WORKMODS_CONFIG_DIR ; la source du registre, avec WORKMODS_REGISTRY_REPO et WORKMODS_REGISTRY_BRANCH.
